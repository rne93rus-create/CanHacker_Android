CanHacker Android START 1.0.0

Приложение для отправки команд START и STOP в Arduino Nano через USB OTG / CH340.
Параметры последовательного порта: 115200, 8N1.

КАК ПОЛУЧИТЬ APK БЕЗ УСТАНОВКИ ANDROID STUDIO
1. Открой https://github.com и войди в аккаунт (или создай бесплатный).
2. Нажми + → New repository.
3. Название: CanHacker-Android-START
4. Выбери Public и нажми Create repository.
5. На странице репозитория нажми Add file → Upload files.
6. Распакуй этот ZIP на компьютере. Перетащи ВСЕ файлы и папки из распакованной папки в окно GitHub, включая папку .github. Если папка .github не отображается в проводнике, включи показ скрытых элементов.
7. Нажми Commit changes.
8. Открой вкладку Actions. Дождись завершения задания Build CanHacker APK с зелёной галочкой.
9. Открой завершённое задание. Внизу страницы найди Artifacts и скачай CanHacker-Android-START-1.0.0.zip.
10. Распакуй скачанный архив: внутри будет app-debug.apk. Перенеси APK на планшет и установи.

Важно:
- Репозиторий должен быть Public, чтобы использовать бесплатные минуты GitHub Actions без ограничений для публичных репозиториев на стандартных исполнителях.
- Не загружай в репозиторий пароли, ключи или личные данные.
- Приложение отправляет ASCII-команды START\n и STOP\n; оно не прошивает Arduino.
- На планшете сначала подключи Arduino через OTG, открой приложение и нажми «Подключить Arduino».
